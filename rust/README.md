# The Rust Programming Language
This directory contains code and notes from the online book ["The Rust Programming Language"](https://doc.rust-lang.org/book/title-page.html)

# 1. Getting started

Cargo is an package manager and build system (like node and npm) 
We can use Cargo to start a project and manage dependences, 

```
cargo new <name_app>
cargo build
cargo run
```
